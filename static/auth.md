# auth.md

Ashford Wide (ashfordwide.com) is a static community information site. It has no user accounts, no login or session system, no API, and no OAuth infrastructure. There is nothing here for an agent to register for or authenticate against.

## Agent audience

Any automated agent, crawler, or scanner reading this site.

## Registration / provisioning endpoints

None. This site does not issue accounts, credentials, API keys, or sessions of any kind, and has no endpoint that creates or provisions one.

## Supported methods

None. There is no authentication or authorization mechanism — public pages are served statically and identically to every visitor, human or automated.

## Credential use

Not applicable. No part of this site requires, accepts, stores, or acts on credentials on behalf of a user or agent. Where the site links to third-party services (e.g. PayPal for donations), those services handle their own authentication independently and are out of scope for this document.
